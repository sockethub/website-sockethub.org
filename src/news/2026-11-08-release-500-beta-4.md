Sockethub [5.0.0-beta.4](https://github.com/sockethub/sockethub/releases/tag/v5.0.0-beta.4)
is available on the `next` release channel:

```
npm install -g sockethub@next
```

The container image is available at `ghcr.io/sockethub/sockethub:next`.

This release fixes WhatsApp recipient numbers that omit the leading plus sign,
and restores real product images for Amazon pages and Reddit galleries in
metadata previews. See the
[full changelog](https://github.com/sockethub/sockethub/releases/tag/v5.0.0-beta.4).
