Sockethub [5.0.0-beta.3](https://github.com/sockethub/sockethub/releases/tag/v5.0.0-beta.3)
adds a WhatsApp platform for sending text messages through Meta's WhatsApp
Business Cloud API:

```
npm install -g sockethub@next
```

The container image is available at `ghcr.io/sockethub/sockethub:next`.

## WhatsApp Business messages

[`@sockethub/platform-whatsapp`](https://github.com/sockethub/sockethub/tree/v5.0.0-beta.3/packages/platform-whatsapp)
is a stateless, outgoing-only platform. Set credentials and send; there is no
connect step or webhook endpoint to host. Your application obtains the Meta
access token and handles incoming messages and recipient discovery.

The platform sends text as a WhatsApp Business phone number, not a personal
WhatsApp account. The actor ID is the phone number ID from Meta, and the
recipient is a phone number in international format. Free-form text is subject
to Meta's 24-hour messaging window; template messages, media, and incoming
messages are not supported.

See the [WhatsApp section of the platforms page](/platforms/#whatsapp) for a
credentials and send example, limits, and setup details.

Beta.3 also fixes the metadata package dependency declaration. The
[full changelog](https://github.com/sockethub/sockethub/releases/tag/v5.0.0-beta.3)
has the release details.
