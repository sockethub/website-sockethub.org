# What can you build with Sockethub?

Choose a task to see where Sockethub fits, what the first request looks like,
and which parts of the application you still need to build.

## [Add IRC and XMPP chat to your web app](/use-cases/web-chat/)

Let people join an existing IRC channel or message their XMPP contacts from
a web interface you control. Useful for a community chat page or a custom
messaging client.

## [Build a web-based RSS reader](/use-cases/rss-reader/)

Fetch RSS and Atom feeds that block cross-origin browser requests, then use
the parsed entries in a reader or a project news dashboard.
